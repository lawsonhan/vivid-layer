# Contributing

Thank you for helping improve Vivid Layer.

## Before opening a pull request

1. Keep changes scoped to the public Registry item being improved.
2. Preserve third-party copyright and attribution notices.
3. Do not add paid components, private application code, credentials, or
   proprietary assets.
4. Run:

   ```bash
   pnpm install
   pnpm registry:check
   pnpm registry:build
   ```
